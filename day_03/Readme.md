# Python Task Tracker

A simple command-line task tracker built with Python.

## Features

- Add tasks
- View tasks
- Mark tasks as complete
- Delete tasks
- Organized using OOP and modules

## Tech Stack

- Python 3.12+
- Git and GitHub
- Virtual environment

## Project Structure

```text
python-task-tracker/
├── task_tracker/
│   ├── __init__.py
│   ├── models.py
│   ├── tracker.py
│   └── cli.py
├── main.py
├── requirements.txt
└── README.md
```

## Getting Started

### 1. Clone the repository

```bash
git clone [https://github.com/YOUR_USERNAME/python-task-tracker.git](https://github.com/YOUR_USERNAME/python-task-tracker.git)
cd python-task-tracker
```

### 2. Create a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate   # macOS/Linux
.venv\Scripts\activate      # Windows
```

### 3. Run the app

```bash
python main.py
```
